# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Назначение приложения

Приложение Business Metrics Analyzer предназначено для анализа основных показателей деятельности предприятия.

## 2. Бизнес-задача

Предприятию необходимо анализировать данные о ежемесячной выручке и рассчитывать показатели эффективности для оценки результатов своей деятельности.

## 3. Основные требования

Приложение должно:

- хранить данные о выручке предприятия по месяцам;
- отображать исходные данные в удобном виде;
- рассчитывать среднюю выручку;
- рассчитывать показатель рентабельности;
- выводить полученные результаты пользователю.

## 4. Пользователи приложения

Основными пользователями приложения могут быть сотрудники предприятия, руководители и бизнес-аналитики, которым необходимо оценивать основные показатели деятельности организации.

## 5. Ожидаемый результат

В результате работы приложения пользователь должен получить информацию о выручке предприятия и рассчитанных показателях эффективности, которые могут использоваться для анализа деятельности предприятия.
